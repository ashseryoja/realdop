# Real Dop — Coming soon

Превью-страница: анимированное небо с облаками, хромовый 3D-логотип с эффектом жидкости и надпись «Coming soon».

- Three.js (через CDN, importmap), без сборки
- `assets/models/realdop.glb` — модель для десктопа, `realdop-lite.glb` — для экранов до 768px

Локальный запуск:

```bash
python3 -m http.server 5178
```
